# Projeck
1. Deskripsi Masalah dan Solusi
Masalah: Petani/pedagang mangga lokal (khususnya Mangga Reang) sering kali kesulitan dalam memperluas jangkauan pasar, mengelola inventaris stok buah, serta melakukan pencatatan transaksi penjualan secara transparan dan efisien.
Solusi: Aplikasi Juragan Mangga Reang hadir sebagai platform digital berbasis web/mobile yang menghubungkan langsung antara petani/penjual dengan pembeli, serta menyediakan fitur manajemen inventaris dan pencatatan transaksi yang terintegrasi.

3. Fitur Utama dan Target Pengguna
Fitur Utama:
   * Katalog produk mangga lengkap dengan informasi harga dan ketersediaan stok.
   * Sistem pemesanan dan transaksi online.
   * Dashboard manajemen inventaris bagi penjual/juragan.
   * Laporan penjualan berkala.
Target Pengguna:
   * Petani / Pengepul Mangga (Juragan): Sebagai pengelola toko, stok, dan pencatat transaksi.
   * Pembeli / Konsumen (Retail & Grosir): Yang ingin memesan mangga berkualitas langsung dari sumbernya.
3. Tech Stack dan Arsitektur
 * Frontend: (Contoh: React.js / Next.js / Tailwind CSS)
 * Backend: (Contoh: Node.js / Express / Python / Laravel)
 * Database: (Contoh: PostgreSQL / MongoDB / MySQL)
 * Arsitektur: (Contoh: RESTful API / MVC Pattern)
   
4. Cara Instalasi / Menjalankan Aplikasi
Ikuti langkah-langkah di bawah ini untuk menjalankan proyek secara lokal di komputer Anda:
# 1. Clone repositori ini
git clone https://github.com/username/juragan-mangga-reang.git

# 2. Masuk ke direktori project
cd juragan-mangga-reang

# 3. Install dependencies untuk backend & frontend
npm install

# 4. Jalankan aplikasi mode development
npm run dev

5. Environment Variables
Buat file .env di root direktori proyek Anda dan sesuaikan variabel berikut:
PORT=5000
DATABASE_URL=your_database_connection_string
JWT_SECRET=your_secret_key
